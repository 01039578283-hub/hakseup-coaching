식·표·그래프에서 같은 관계를 읽는 연습

식을 계산할 수 있어도 그래프가 무엇을 나타내는지 설명하지 못할 수 있습니다. 축의 양과 단위를 읽고 표의 값을 식과 대조해 보세요. 점의 위치뿐 아니라 변화와 적용 범위를 자신의 말로 표현합니다.

먼저 살펴볼 것

  • x와 y가 무엇을 나타내는지 먼저 정했나요?
  • 표의 값을 그래프의 점과 연결할 수 있나요?
  • 선이 계속 이어진다고 실제 상황도 무한히 이어진다고 생각하나요?

실천 순서

  1. 양과 범위 읽기

    x, y의 뜻과 단위를 정하고 문제에서 허용한 범위를 적습니다. 시간처럼 음수가 의미 없는 상황도 구분합니다.

  2. 식에서 표 만들기

    서로 다른 입력값을 대입해 출력값을 구합니다. 같은 차이로 입력이 늘 때 출력이 어떻게 달라지는지 살핍니다.

  3. 표에서 점 표시

    축의 눈금과 단위에 맞춰 좌표를 표시합니다. 두 축의 눈금이 같은 크기라고 가정하지 않습니다.

  4. 관계를 말로 정리

    처음 값과 변화량을 구분해 설명합니다. 그림의 모양만 보고 식을 추정하지 말고 실제 값과 조건으로 검토하세요.

예시와 해설

먼저 생각해 보기

y = 3x + 2에서 x가 0, 1, 2일 때 y를 구하고 두 수가 어떤 관계인지 설명해 보세요.

y = 3x + 2의 입력과 출력
x계산y좌표
03 × 0 + 22(0, 2)
13 × 1 + 25(1, 5)
23 × 2 + 28(2, 8)
해설 열기

y는 각각 2, 5, 8입니다. x가 1 늘 때 y는 3 늘고 x = 0일 때 y = 2입니다. y = 3x와 다르게 두 양의 비율이 항상 3인 관계는 아닙니다. 상황 문제라면 x의 범위와 두 양의 단위도 별도로 확인합니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

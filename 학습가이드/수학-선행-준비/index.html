실천 순서

  1. 현재 개념 설명

    교과서 정의나 예제를 자신의 말로 설명합니다. 공식의 기호와 적용 조건이 무엇인지 물어보세요.

  2. 기본 적용 확인

    현재 범위의 대표 문제를 도움 없이 풀고 첫 식의 이유를 적습니다. 맞힌 개수만으로 준비 여부를 결정하지 않습니다.

  3. 시간 뒤 재확인

    다른 날 비슷한 문제에서 다시 시작해 봅니다. 답을 기억한 문제만 고르지 않도록 조건이 다른 과제도 확인합니다.

  4. 새 범위와 일정 조정

    새 개념에 필요한 이전 개념과 복습 시간을 확인합니다. 현재 과제를 마치기 어렵다면 분량이나 설명을 조정하고 교사와 준비 상태를 상의합니다.

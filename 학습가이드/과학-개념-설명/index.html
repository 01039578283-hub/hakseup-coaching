먼저 살펴볼 것

  • 정의의 낱말은 기억하지만 예시를 말하기 어렵나요?
  • 서로 다른 조건을 빼고 결과만 비교하나요?
  • 예측과 실제 관찰 결과를 구분했나요?

실천 순서

  1. 개념의 말뜻 확인

    교과서 정의의 중요한 용어를 자신의 말로 풉니다. 비슷한 일상어와 교과 개념의 차이를 확인하세요.

  2. 현상의 조건 표시

    대상과 바뀐 조건, 같게 두어야 할 조건을 구분합니다. 문제에 없는 조건을 임의로 추가하지 않습니다.

  3. 개념으로 이유 쓰기

    정의를 반복하기보다 어떤 조건 때문에 어떤 현상이 나타나는지 연결합니다. 설명이 어려우면 예제와 교사 안내를 참고합니다.

  4. 예측과 자료 비교

    조건이 바뀌었을 때 어떻게 될지 예상하고 관찰 자료와 대조합니다. 예상과 관찰이 다르면 조건과 설명을 다시 검토하세요.

예시와 해설

먼저 생각해 보기

같은 부피의 두 물체에서 A의 질량이 20g, B의 질량이 30g입니다. 어느 물체의 밀도가 큰지와 비교 조건을 설명하세요.

해설 열기

밀도는 질량을 부피로 나눈 값입니다. 부피가 같으므로 질량이 더 큰 B의 밀도가 더 큽니다. 부피가 다르다면 질량만으로 비교할 수 없습니다. 이 예시는 개념 적용용 수치이며 실제 측정 실험은 아닙니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

다른 자료에 적용하기

조건 바꾸기

A는 20g·10cm³, B는 30g·20cm³라면 각각 2g/cm³, 1.5g/cm³로 A의 밀도가 큽니다. 같은 부피 조건이 없어졌음을 설명하세요.

다음 확인

현재 단원의 개념 하나에서 정의, 적용 조건, 현상 설명을 연결하세요. 실험 활동은 학교의 안전 지도와 실제 안내에 따릅니다.

학부모는 이렇게 도울 수 있습니다

맞힌 답에서도 비교 조건과 단위를 설명할 수 있는지 봅니다. 계산과 현상 이해는 나누어 확인할 수 있습니다.

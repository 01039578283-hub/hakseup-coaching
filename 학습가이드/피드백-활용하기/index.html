첨삭과 설명을 다음 과제의 행동으로 바꾸기

맞은 답으로 고쳐 놓아도 왜 고쳤는지 설명하지 못하면 비슷한 오류가 다시 생길 수 있습니다. 피드백에서 수정할 부분, 이유, 다음에 할 행동을 골라 보세요. 모든 지적을 한꺼번에 바꾸기보다 이번 과제에서 가장 필요한 것을 먼저 적용합니다.

먼저 살펴볼 것

  • 선생님 표시를 따라 고쳤지만 수정 이유를 말하기 어렵나요?
  • 어떤 피드백부터 반영할지 몰라 과제를 멈추나요?
  • 새 과제에서 같은 오류가 나오는지 확인한 기록이 없나요?

실천 순서

  1. 피드백의 대상 읽기

    내용의 정확성, 풀이의 근거, 답안 형식 중 무엇을 고치라는 것인지 표시합니다. 의미가 모호한 짧은 첨삭은 교사에게 질문합니다.

  2. 수정 이유 쓰기

    이 부분이 틀렸다는 말 뒤에 빠진 조건이나 달라진 의미를 적습니다. 이유를 몰라서 베꼈다면 아직 확인이 필요한 부분으로 남깁니다.

  3. 다음 행동으로 바꾸기

    주의하기 대신 단위를 마지막 줄에 쓰기, 주장 옆에 지문 근거 표시하기처럼 수행할 행동을 고릅니다.

  4. 다른 과제에서 확인

    첨삭을 받은 문제를 고친 뒤 같은 행동이 필요한 새 문제를 풀어 봅니다. 결과를 보고 행동이 도움이 됐는지 판단합니다.

예시와 해설

먼저 생각해 보기

과학 답안에 근거가 부족함이라는 피드백을 받았습니다. 관찰 결과는 온도 10℃에서 4회, 20℃에서 7회였습니다. 무엇을 더 써야 할까요?

해설 열기

주장이 어떤 관찰값에서 나왔는지 연결합니다. 예를 들어 이 두 측정에서 온도가 높았던 조건의 횟수가 4회에서 7회로 많았다고 씁니다. 두 점만으로 모든 온도에서 계속 증가한다고 확장하지 않습니다. 실제 답안에는 해당 과제의 단위와 조건을 사용해야 합니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

오늘 적용

최근 첨삭 하나를 골라 원래 답, 수정 이유, 다음 행동을 적으세요. 표시가 여러 개면 가장 중요한 기준을 교사에게 확인합니다.

다음 확인

다른 과제에서 그 행동을 적용한 부분을 찾아 비교하세요. 새 과제 조건이 다르면 같은 수정 규칙이 적용되는지 다시 검토합니다.

학부모는 이렇게 도울 수 있습니다

지적받은 개수를 세기보다 아이가 어떤 이유를 이해했는지 물어보세요. 부모가 교사의 피드백 의도를 추측해 추가 규칙을 만들지 않습니다.

다음 과제에서 아이가 직접 바꾼 한 부분을 함께 보세요. 완벽하게 수정하지 못했더라도 남은 질문을 말할 수 있는지 살핍니다.

새 교재를 고르기 전에 현재 책의 남은 역할 확인하기

새 책을 시작하면 계획이 새로워 보이지만 같은 개념에서 다시 멈출 수 있습니다. 현재 책을 개념 설명, 기본 적용, 추가 연습 중 어떤 목적으로 쓰는지 먼저 정리하세요. 남은 오답과 질문을 확인한 뒤 다음 자료가 맡을 역할을 선택합니다.

먼저 살펴볼 것

  • 현재 책이 어려운 이유가 개념인지 설명 방식인지 구분했나요?
  • 끝낸 페이지의 대표 문제를 혼자 다시 풀 수 있나요?
  • 새 교재가 기존 책과 같은 과제를 중복하나요?

실천 순서

  1. 책의 역할 적기

    개념을 처음 배우는 책인지, 배운 것을 적용하는 책인지, 평가 조건을 연습하는 자료인지 적습니다. 출판사의 이름이나 단계만으로 현재 학생에게 맞는다고 확정하지 않습니다.

  2. 대표 과제 시도

    현재 범위의 설명과 문제를 직접 해봅니다. 읽고 이해한 부분과 해설을 참고한 부분을 표시하세요.

  3. 남은 복습 목록

    틀린 문제의 개수보다 아직 설명 못한 개념과 반복 오류를 적습니다. 모든 문제를 처음부터 다시 풀기 전에 필요한 범위를 정합니다.

  4. 다음 자료의 목적 정하기

    기존 책으로 보완할지 다른 설명이나 수준의 자료가 필요한지 봅니다. 실제 교재의 목차, 예시와 답안 요구를 확인하고 교사와 상의할 수 있습니다.

예시와 해설

먼저 생각해 보기

기본 교재를 끝냈지만 답을 가리면 분수 덧셈의 첫 식이 어렵습니다. 더 높은 단계의 책부터 사야 할까요?

해설 열기

먼저 현재 책의 설명과 대표 문제로 분수의 의미와 첫 식을 다시 확인합니다. 설명 방식이 맞지 않으면 다른 자료가 필요할 수 있지만 높은 단계라는 이름만으로 선택하지 않습니다. 새 책의 역할은 현재 부족한 수행에 맞춰 정합니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

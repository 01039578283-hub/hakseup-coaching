먼저 살펴볼 것

  • 축과 단위를 읽기 전에 선의 모양으로 판단하나요?
  • 비교한 조건 외의 다른 차이가 있는지 보았나요?
  • 측정한 범위 밖의 결과까지 단정하나요?

실천 순서

  1. 표와 축 읽기

    각 열과 축이 무엇을 나타내는지, 단위와 눈금 간격은 어떤지 적습니다. 같은 높이의 변화라도 눈금이 다르면 값이 다릅니다.

  2. 비교 조건 확인

    변경한 조건과 같게 둔 조건을 찾아 적습니다. 자료에 없으면 확인이 필요한 항목으로 남기세요.

  3. 값으로 관찰 설명

    증가했다는 말 옆에 어느 조건에서 얼마에서 얼마로 바뀌었는지 씁니다. 평균과 개별 측정값은 구분합니다.

  4. 결론의 범위 제한

    측정한 범위에서 자료가 말해 주는 내용을 정리합니다. 원인을 확정하려면 비교 조건과 다른 근거가 필요한지 확인하세요.

예시와 해설

먼저 생각해 보기

연습용 가상 자료: 빛을 비춘 시간이 1시간, 2시간, 3시간일 때 관찰값이 각각 4, 7, 7입니다. 시간이 늘면 관찰값이 항상 같은 양만큼 증가한다고 말할 수 있을까요?

읽기 연습용 가상 관찰 자료 · 관찰량과 단위는 미지정
빛을 비춘 시간관찰값앞 조건과의 차이
1시간4—
2시간7+3
3시간70
해설 열기

1시간에서 2시간은 3 증가했지만 2시간에서 3시간은 증가하지 않았으므로 같은 양의 증가라고 할 수 없습니다. 관찰값의 뜻과 단위, 비교 조건도 실제 보고서에서는 확인해야 합니다. 이 세 값으로 4시간 이후를 단정할 수 없습니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

인쇄된 그림이 작으면 값과 눈금을 확인할 수 있는 원자료를 찾아 주세요. 대략적인 그림 모양을 정확한 수치처럼 기록하지 않습니다.

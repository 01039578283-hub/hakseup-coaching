먼저 살펴볼 것

  • 최근 시험지와 첫 풀이, 첨삭 자료를 준비했나요?
  • 점수 변화와 과제의 난도, 도움 범위를 함께 보나요?
  • 상담 뒤 목표와 재확인 자료가 구체적인가요?

실천 순서

  1. 대표 자료 고르기

    잘한 과제와 어려운 과제를 함께 고릅니다. 오래된 점수표만 가져가기보다 현재 수행이 보이는 최근 자료를 준비하세요.

  2. 학생 질문과 도움 표시

    해설 없이 한 부분, 교사나 부모와 한 부분을 표시합니다. 학생이 직접 묻고 싶은 질문도 따로 적습니다.

  3. 목표와 수업 조건 확인

    내용의 목표와 실제 개설 학년, 과목, 시간, 비용을 구분해 확인합니다. 자료상 확인이 안 된 조건은 확인 필요로 남깁니다.

  4. 다음 확인 합의

    다음에 어떤 과제를 어떤 도움 범위로 할지 정합니다. 확인 시점과 피드백을 받는 방법도 해당 교사나 지점과 확인하세요.

예시와 해설

먼저 생각해 보기

점수가 70점에서 80점으로 올랐지만 두 시험의 범위와 난도가 다릅니다. 상담에서 어떤 자료를 추가로 볼까요?

해설 열기

비슷한 개념의 문제에서 처음 식을 혼자 정하고 풀이 이유를 설명했는지 비교할 수 있습니다. 부모가 첫 식을 말해 준 과제는 도움 받은 수행으로 표시합니다. 점수 상승은 결과로 남기되 그것만으로 동일 조건의 학습 변화를 확정하지 않습니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

다음 확인

상담에서 정한 목표와 비슷한 조건의 과제를 다시 보세요. 좋아진 부분, 그대로인 부분, 아직 판단하기 어려운 부분을 나눕니다.

학부모는 이렇게 도울 수 있습니다

학생 대신 모든 상담을 설명하기보다 본인의 첫 판단과 질문을 말할 기회를 주세요. 민감한 자료는 상담에 필요한 범위만 준비합니다.

상담 결과를 능력의 고정 평가로 받아들이지 말고 다음 활동과 확인 자료로 연결합니다. 실제 교사의 진단과 운영 조건은 직접 확인하세요.

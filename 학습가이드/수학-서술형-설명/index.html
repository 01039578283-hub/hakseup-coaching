먼저 살펴볼 것

  • 어떤 조건으로 첫 식을 썼는지 말할 수 있나요?
  • 나누거나 제곱한 단계의 조건을 남겼나요?
  • 계산 결과와 문제에서 요구한 결론을 구분하나요?

실천 순서

  1. 답안 요구 표시

    구하기, 설명하기, 증명하기와 주어진 표현 조건을 확인합니다. 학교의 평가 기준이 있으면 함께 봅니다.

  2. 조건에서 첫 식 연결

    문제의 말이 어떤 등식이나 관계를 뜻하는지 짧게 적습니다. 정의한 문자는 무엇을 나타내는지도 씁니다.

  3. 변형 이유와 조건 남기기

    양변에 같은 수를 더하거나 나누는 등 핵심 변형의 이유를 표시합니다. 0으로 나누지 않는 조건처럼 필요한 제한을 지우지 않습니다.

  4. 원래 질문으로 마무리

    얻은 값이 문제의 범위와 단위를 만족하는지 확인하고 요구한 결론을 문장으로 씁니다. 풀이 줄 수는 일률적으로 정하지 않습니다.

예시와 해설

먼저 생각해 보기

가로가 세로보다 3cm 긴 직사각형의 둘레가 26cm입니다. 세로를 구하는 첫 식과 이유를 설명하세요.

해설 열기

세로를 x cm라 두면 가로는 x + 3 cm입니다. 둘레는 두 가로와 두 세로의 합이므로 2x + 2(x + 3) = 26입니다. 정리하면 4x + 6 = 26, x = 5입니다. 세로 5cm, 가로 8cm는 둘레 26cm와 양의 길이 조건을 만족합니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

다른 자료에 적용하기

독립 연습

다음 확인

실제 답안에서 첫 식의 이유와 마지막 조건 검토가 있는지 확인하세요. 교사 피드백이 다르면 필요한 설명의 범위를 질문합니다.

분수 계산을 같은 전체와 조각의 크기로 설명하기

분모와 분자를 더하는 오류를 계산 순서만 암기해서 고치기 어려울 수 있습니다. 무엇을 하나의 전체로 보고 어떤 크기의 조각을 세는지 확인하세요. 그림과 수직선에서 크기를 설명한 뒤 식을 만들면 계산의 의미를 다시 볼 수 있습니다.

먼저 살펴볼 것

  • 분수가 어떤 전체의 얼마인지 설명할 수 있나요?
  • 분모가 다른 두 조각을 그대로 같은 종류처럼 더하나요?
  • 계산 결과가 두 수보다 어떻게 커지는지 예상하나요?

실천 순서

  1. 전체와 단위 조각 정하기

    같은 크기의 전체를 기준으로 분모만큼 똑같이 나누었다고 설명합니다. 서로 다른 전체의 일부를 바로 비교하지 않습니다.

  2. 그림이나 수직선으로 크기 보기

    1/2과 1/3을 같은 길이에서 표시합니다. 표시 위치와 조각 수가 무엇을 뜻하는지 말합니다.

  3. 같은 조각으로 바꾸기

    1/2은 3/6, 1/3은 2/6으로 나타낼 수 있습니다. 수의 크기는 그대로이고 세는 조각의 크기가 같아졌음을 설명합니다.

  4. 어림과 식을 대조

    3/6 + 2/6 = 5/6입니다. 양수인 1/3을 더했으므로 1/2보다 커야 하며 1보다 작은 결과인지 그림에서 확인합니다.

예시와 해설

먼저 생각해 보기

1/2 + 1/3을 2/5라고 쓴 학생에게 어떤 그림을 보여줄 수 있을까요?

해설 열기

같은 길이의 막대를 6등분해 1/2을 3칸, 1/3을 2칸으로 표시합니다. 모두 5칸이므로 5/6입니다. 2/5는 1/2보다 작으므로 양수인 1/3을 더한 결과로 맞지 않습니다. 분모는 세는 조각의 크기와 연결해 설명합니다.

학습 방법을 설명하기 위해 만든 연습입니다. 학교·교재에서 배운 범위에 맞춰 사용하세요.

다른 자료에 적용하기

다른 수

1/4 + 1/2을 같은 전체에서 표시해 보세요. 1/2을 2/4로 바꾸면 3/4이며 왜 조각 크기를 맞췄는지 말합니다.

다음 확인

그림 없이 먼저 식을 세우고 막혔을 때 그림을 다시 사용하세요. 이미 배운 범위에서 분수와 소수의 크기 비교도 연결할 수 있습니다.

학부모는 이렇게 도울 수 있습니다

정해진 순서를 외우게 하기 전에 어떤 조각을 세는지 물어보세요. 학생의 그림에서 전체의 크기가 같은지도 함께 봅니다.

식이 틀렸을 때 답부터 알려주기보다 결과의 대략적인 크기를 생각할 기회를 주세요. 어림만으로 정답을 확정하지는 않습니다.

# 학습코칭.kr 지점별 영어·수학 안내

작업일: 2026-09-21. 로컬 작업이며 GitHub push 및 배포는 수행하지 않았습니다.

## 주소와 범위

- 기존 `/지점안내/서울/명일점/` 주소를 그대로 유지합니다.
- 새 주소 예: `/지점안내/서울/명일점/명일동수학학원/`, `/지점안내/서울/명일점/명일동영어학원/`.
- 영어 371편, 수학 371편: 371개 동네에 742개 새 페이지입니다.
- 원고와 매칭되는 지점은 188곳입니다. 전체 193곳을 371곳으로 표시하지 않습니다.
- 원고에 대응하는 동네가 없는 송파위례점·다산지금점·별가람점·옥길스타점·위례창곡점은 기존 지점 페이지의 내용만 보강했습니다. 다른 지점의 원고를 중복 배정하지 않았습니다.
- 루트 1개, 시도 16개, 지점 193개의 기존 허브 210개를 보강했습니다.
- 기존 전국학원·과목별학원 원고, 주소, 리다이렉트, 네이버·구글 확인 태그, 통계 수집 설정은 보존했습니다.

## 원고와 사실 검증

- 입력 엑셀은 읽기 전용으로 처리했고 파일 SHA-256을 기록했습니다.
- 각 파일의 두 시트는 같은 371편을 보관합니다. 깨끗한 `Sheet1`을 사용하고 중복 742개 레코드는 추가 페이지로 세지 않았습니다.
- 내보내기 시트의 `_x000D_`와 특수문자 손상, 영어 58행의 외국어 작성 흔적을 그대로 출력하지 않았습니다.
- 잘못된 도시 접두사와 혼합 과목 제목 등 17개 제목 매칭을 두 원고 및 센터 데이터에 대조했습니다. 잘못된 본문 지명도 가져오지 않고 검증된 센터 주소만 사용했습니다.
- 원고의 학습 주제에 따라 설명·직접 해볼 점검·복습 기록·FAQ를 새로 작성했습니다. 확인되지 않은 지도 실적, 교사, 시간표, 결과를 사례로 만들지 않았습니다.
- 기존 센터의 과목별 개설 학년·학교·조건을 반영했습니다. 미확인 과목 15개 페이지에는 확인 안내를 유지하고 해당 과목 Service를 만들지 않았습니다. 추가 확인 학년이 있는 31개 페이지도 조건을 유지했습니다. 두 수치는 중복될 수 있습니다.
- 모두오름 지점은 실제 등록 학원명을 상단에 표시했습니다. 학교 목록은 상담 참고 정보로 설명합니다.
- 학습 방법의 공통 블록은 여러 페이지에서 재사용됩니다. 제목·설명이 서로 다르거나 원문을 다시 썼다는 사실만으로 유사문서 판정이나 검색 순위가 보장되지는 않습니다.

## 연결과 메타데이터

- 지점 FAQ 바로 뒤에 해당 지점의 모든 동네별 영어·수학 버튼을 배치했습니다.
- 각 새 글에서 부모 지점, 지역 목록, 같은 동네의 다른 과목, 같은 지점의 관련 동네와 학습가이드·진단상담으로 연결합니다.
- 새 글의 title/H1/설명/canonical/OG/Twitter를 해당 동네와 과목에 맞춰 구성했습니다.
- Article abstract는 화면 첫 요약과 일치합니다. FAQPage는 화면 FAQ와 동일합니다.
- 실제 센터의 EducationalOrganization/LocalBusiness 식별자를 공유하고, 검증된 과목의 Service를 연결했습니다. 동네마다 가상의 별도 사업체를 만들지 않습니다.
- 허브의 ItemList·hasPart와 하위 글의 isPartOf·BreadcrumbList를 연결했습니다. 하위 글이 없는 지점은 빈 ItemList를 만들지 않습니다.
- 사이트맵: 기존 4,953개 + 새 742개 = 로컬 5,695개. 기존 URL 삭제 없음.
- RSS: 새 글 20개와 기존 30개, 총 50개. 새 항목은 본문과 절대경로 링크·이미지를 포함합니다. llms.txt에 탐색 안내를 추가했습니다.

## 이미지와 화면

- 대표이미지(숨김) → 본문이미지(전체 표시) → 해당 센터 지도 순서입니다.
- 본문·지도 ALT: `페이지 제목 본문`, `페이지 제목 지도`.
- 기존 지점의 학습 공간 사진과 접힘 기본값은 유지했습니다.
- 별도 대형 이미지 복제나 프레임워크 추가 없이 기존 자산·반응형 이미지·메뉴를 재사용합니다.
- 모바일 본문 16px, 이동 버튼 최소 48~52px. 지점의 동네 버튼은 좁은 화면에서 한 열, 일반 모바일에서 두 열입니다.
- 기존 스크롤 여백이 두 번 적용되던 목차 이동을 이 페이지 묶음에서 보정했습니다.

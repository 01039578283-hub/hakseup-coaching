계획·자기주도

개인별 맞춤 학습 플랜 관리: 진도보다 수행을 보고 조정하기

맞춤 계획은 학생을 고정된 유형으로 분류하는 표가 아닙니다. 현재 할 수 있는 과제, 도움이 필요한 단계, 실제로 사용할 수 있는 시간을 확인해 다음 분량을 조정하는 과정입니다.

게시·정보 확인 2026.10.02 · 학생과 학부모를 위한 학습 안내

실천 순서 확인동네 수업과 연결하기

현재 수준을 과목 안에서 나누어 보기

수학 전체를 잘한다거나 영어 전체가 약하다는 평가 대신 구체적인 과제에서 살펴봅니다. 개념 설명은 가능하지만 조건이 길어지면 막히는지, 단어 뜻은 알지만 문장을 쓰기 어려운지 확인하세요. 최근 과제와 직접 수행한 짧은 확인 자료를 바탕으로 강점과 어려움을 구분합니다. 한 번의 결과를 학생의 고정된 능력으로 해석하지 않습니다.

난도·분량·도움의 양을 따로 조정하기

문제가 너무 어려우면 기초 개념과 예제로 돌아가고, 이해는 있지만 시간이 부족하면 분량을 줄일 수 있습니다. 처음에는 힌트나 예시를 제공하고 점차 혼자 수행하는 부분을 늘립니다. 쉬운 과제만 계속 주거나 도움을 갑자기 모두 없애기보다 학생이 어느 단계에서 다시 설명할 수 있는지 확인하는 것이 중요합니다.

학생과 계획의 완료 기준 합의하기

“한 단원 끝내기” 옆에 무엇을 확인하면 완료인지 적습니다. 설명하기, 새 문제 적용하기, 틀린 문장 고치기처럼 행동으로 정하세요. 계획은 학생이 이해하고 선택할 수 있어야 합니다. 보호자와 담당자는 일정과 필요한 자원을 지원하되 학생의 기록을 매번 감시하는 방식으로 운영하지 않습니다.

주간 점검에서 한 가지씩 바꾸기

예상 시간과 실제 시간, 혼자 수행한 부분과 질문한 부분을 비교합니다. 계획이 밀렸다면 원인이 분량·난도·일정 중 무엇인지 보고 다음 주에 한 항목부터 조정하세요. 여러 변수를 한꺼번에 바꾸면 어떤 변화가 도움이 되었는지 파악하기 어렵습니다. 진도표의 칸보다 실제 설명과 적용 결과를 확인합니다.

조정 예시

문제 풀이를 시작할 때마다 식을 고르기 어려운 학생에게는 대표 예제와 새 문제를 비교하는 과제를 먼저 배치할 수 있습니다. 풀이 시작점을 혼자 설명하게 되면 힌트를 줄이고 조건이 다른 문제로 넘어갑니다. 단순히 과제 수를 늘리는 조정과 구분됩니다.

이 예시는 방법을 설명하기 위한 예이며 실제 학생의 성적이나 수업 결과를 제시하지 않습니다.

바로 실천할 확인 순서

  1. 과목별로 가능한 수행과 막힌 단계를 나눕니다.
  2. 완료 기준과 필요한 도움을 정합니다.
  3. 실제 시간과 질문을 기록합니다.
  4. 점검 결과를 보고 다음 주 한 항목을 조정합니다.

함께 확인할 점

시각형·청각형처럼 학생을 고정된 학습 유형으로 나눠 수업 방식을 제한하지 않습니다. 과제의 성격과 실제 수행을 바탕으로 방법을 비교하세요.

학생·학부모가 자주 묻는 질문

매주 계획을 바꾸면 일관성이 없어지지 않나요?

목표를 유지하면서 분량이나 도움의 양을 조정할 수 있습니다. 변경 이유를 적으면 무엇을 유지하고 무엇을 바꿨는지 확인하기 쉽습니다.

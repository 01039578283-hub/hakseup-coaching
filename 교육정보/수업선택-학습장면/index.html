학원·코칭 선택

학원 수업 선택: 설명·질문·혼자 풀기 장면을 확인하세요

수업의 규모나 시설 외에도 실제 학습 장면을 확인해 보세요. 설명을 이해하지 못했을 때, 과제에서 막혔을 때, 혼자 다시 풀 때 어떤 지원을 받는지 같은 기준으로 물을 수 있습니다.

게시·정보 확인 2026.10.06 · 학생과 학부모를 위한 학습 안내

실천 순서 확인동네 수업과 연결하기

교사의 설명이 필요한 상황을 제시

최근 학생이 막힌 개념이나 문항을 가져가 어떤 방식으로 설명하는지 묻습니다. 담당 과목과 수업의 학년, 반 수준도 확인하세요. 경력이나 자격 소개는 참고하되 학생의 질문에 어떤 자료와 예시를 사용하는지도 살펴봅니다. 다른 학생의 성적 사례만으로 우리 아이의 결과를 정하지 않습니다.

개별 질문의 시간과 절차 확인

수업 중 바로 질문하는지, 별도 시간이나 기록으로 질문하는지 물어봅니다. 질문을 한 뒤 학생이 스스로 이해한 내용을 확인하는 절차도 중요합니다. 소수 인원이라고 항상 충분한 개별 시간이 보장되는 것은 아닙니다. 실제 인원과 교사의 설명·피드백 시간을 따로 확인하세요.

커리큘럼은 교재 목록보다 연결 방식

학교 진도, 기초 보완, 연습과 피드백이 어떻게 이어지는지 묻습니다. 같은 과목 이름이라도 자료의 역할과 과제 난도는 다를 수 있습니다. 학생이 현재 할 수 있는 내용과 필요한 도움을 기준으로 계획이 조정되는지도 확인합니다. 온라인 제공이나 보충 자료는 실제 이용 조건을 문의합니다.

혼자 수행한 결과가 다음 과제에 반영되는지

설명을 들은 뒤 다시 풀어 본 답안과 남은 질문을 어떻게 확인하는지 봅니다. 상담이나 체험이 가능하다면 학생의 느낌과 수행을 함께 기록할 수 있습니다. 체험 여부와 조건은 지점마다 다를 수 있으므로 먼저 확인하세요. 최신 시설이나 큰 프로그램 이름만으로 수업 적합성을 결정하지 않습니다.

같은 장면으로 비교하는 예

두 수업에 “문제를 읽고도 첫 식을 못 세운 학생은 어떤 설명을 듣고 무엇을 다시 해보나요?”라고 같은 질문을 합니다. 설명 자료, 개별 질문 절차, 재풀이 확인을 각각 기록하세요. 실제 학습 과정에 대한 답을 비교하면 반 이름만 비교하는 것보다 판단 근거가 분명해집니다.

방법을 설명하기 위한 예시입니다.

바로 실천할 확인 순서

  1. 최근 막힌 과제의 설명 방법을 묻습니다.
  2. 질문 시간·절차·수업 인원을 확인합니다.
  3. 학교 진도와 보완의 연결을 살펴봅니다.
  4. 독립 풀이 결과가 반영되는지 확인합니다.

학생·학부모가 자주 묻는 질문

개별 맞춤 수업은 모두 일대일인가요?

수업 이름만으로 판단할 수 없습니다. 반의 실제 인원과 개인별 설명·질문 시간, 혼자 풀기와 재확인 방식을 따로 확인하세요.

우리 동네 수업 상담에서 이어서 확인하기

설명 뒤 혼자 못 푼 학생에게 어떤 과제와 피드백을 연결하나요?

학생의 학년과 현재 교재, 최근 풀이·과제 기록을 준비하세요. 동네 안내에서 참고 지점을 찾고 지점 페이지의 실제 위치·학년·과목 자료를 확인할 수 있습니다. 현재 시간표와 필요한 지원은 해당 지점에 문의하세요.

우리 동네 학원 찾기지점의 위치·수업 안내지점별 선생님 소개
